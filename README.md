# Cinematic Portfolio

Open `index.html` in any browser. No build step needed.

## Edit these first
- Name / headline: search for "Samiul" and the `words` string in the script
- Projects: the `projects` array in the script (title, description, tags)
- Links: `mailto:you@example.com`, GitHub, LinkedIn, and each project's View Code / Live Demo `href="#"`
- Tech stack: the `stack` object in the script
- Colors: CSS variables at the top (`--accent`, `--bg`, `--glow`)
